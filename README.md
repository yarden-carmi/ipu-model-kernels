# ipu-model-kernels

The output of [ipu-kernelgen](https://github.com/yarden-carmi/ipu-kernelgen): IPU kernels for the layers of
popular models, and the database of what runs on the chip. Written by the loop; do not edit by hand.

What is here and how to use it: ipu-kernelgen's `docs/spec.md` (section "Output repository contents"), the
single source of truth.
